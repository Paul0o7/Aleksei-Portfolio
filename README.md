# Aleksei Macatuno Portfolio

The website is `index.html`. All photos live in the `images` folder.

## Editing text
Open `index.html`, find the sentence you want to change (Ctrl+F / Cmd+F), edit it, and commit.

## Adding a project
1. Upload the photo into the `images` folder.
2. In `index.html`, search for `HOW TO ADD A NEW PROJECT` and follow the steps there.

## Replacing a photo
Upload the new photo into `images` with the exact same file name as the old one. The site will use the new one automatically.

Changes show up on the live site about a minute after you commit.
